⚔️ 열역학 카드 RPG: 위대한 과학자들과의 연금술 레이드 v4

2022 개정 <물질과 에너지> 열화학과 화학 변화의 자발성 — 개인 레이드 · 3인 협동 레이드 · 연습 모드

⚠️ 이 노란 안내가 계속 보이고 버튼이 눌리지 않는다면, 파일 미리보기 화면에서 열려서 게임 프로그램(JavaScript)이 실행되지 않는 상태입니다.
📱 아이폰은 파일을 바로 열지 말고, 선생님이 알려 준 링크를 Safari 주소창에서 열어 주세요.
📘 게임 방법 (처음이라면 꼭 읽어 보세요)
  1. 층마다 과학자 마스터(체력 150)가 나옵니다. 문제를 맞히면 50 피해를 주고, 틀리면 마스터의 반격(20~25)으로 파티 체력(100)이 줄어듭니다.
  2. FLOOR 1 열화학 반응식과 열량 · FLOOR 2 헤스 법칙 · FLOOR 3 엔트로피와 자발성. 3개 층을 모두 돌파하면 클리어!
  3. 개인전은 행동력(AP)을 써서 카드를 발동합니다. 3인 협동전은 서로 다른 정보를 보는 세 클래스가 말로 정보를 주고받고, 각자 PIN을 입력해 합동 공격합니다.
  4. 점수: 한 번에 정답 100점 · 한 번 틀리고 정답 70점 · 두 번 틀리고 정답 40점 · 세 번 틀리면 0점(정답 공개). 비전서 도움을 받아 풀면 −20점, 힌트는 −30점이라 도움 없이 한 번에 푸는 것이 가장 높은 점수예요!
  5. 이름을 쓰고 플레이하면 랭킹 보드판에 기록돼요. 화면의 ⏱ 타이머로 걸린 시간이 재어지고(해설 팝업을 읽는 동안은 멈춰요), 점수가 같으면 더 빨리 끝낸 사람이 위로 올라갑니다. (연습 모드는 랭킹에 반영되지 않아요)
  6. 틀린 문제는 오답 노트에 저장되고, 게임이 끝나면 학습 리포트로 개념별 정답률을 볼 수 있습니다.
🎯 학습 목표: 열량 계산 · 반응 엔탈피와 헤스 법칙 · 엔트로피와 자발성(ΔH, ΔS, 온도 조건)

🧙‍♂️ 개인전 (Solo 레이드)

혼자서 아크메이지의 모든 열화학 마법을 운용해 3개 층의 마스터를 돌파합니다.

• 특징: 행동력(AP), 심화 비전서(+1 AP 및 화력 버프), 힌트(−30점), 풀이 수준에 맞춰 난이도 자동 조절
• 문제: 계산·카드 문제 + 개념 카드 문제(열량계, 에너지 도표, 엔트로피, 오개념 등)

🛡️ 3인 협동전 (같은 방 코드)

세 명이 같은 방 코드로 입장하면 서포터·커맨더·딜러 클래스가 랜덤 배정됩니다. 각자 일부 정보만 보입니다!

• 방식: 정보를 말로 브리핑 → 각자 PIN을 불러 주고 세 명 모두 같은 PIN을 입력 → 세 명 모두 각자 발사 버튼을 한 번씩 누르기 (정확히 같은 순간일 필요는 없어요)
• 인터넷 연결 없이 기기마다 같은 문제와 같은 결과가 나옵니다.

📖 연습 모드

체력·행동력 걱정 없이 개념을 익히는 모드입니다.

• 특징: 틀려도 반격이 없고, 해설을 읽은 뒤 같은 문제를 다시 풀 수 있습니다. 시작 층을 고를 수 있어요.

같은 번호면 같은 문제 세트가 나옵니다 (선생님이 반 전체에 같은 세트를 줄 때 사용).

📡 3인 협동 레이드 입장 설정

세 명이 같은 4자리 방 코드를 입력하고, 서로 다른 크리스탈(A/B/C)을 하나씩 골라 입장하세요. 클래스는 층마다 새로 섞여 배정됩니다!

🔮 STEP 2. 내 입장 크리스탈 선택 (직업은 블라인드!)
🧙‍♂️ 아크메이지 (수식 마법사 · 서포터)
화학 반응식, 몰수 또는 분자량, 상태 기호와 기체 몰수 변화(Δn)를 해독합니다.

⚔️ 파이로 블래스터 (화력 집행관 · 딜러)
두 동료의 브리핑을 받아 정/역반응과 최종 조건을 확정합니다.

문제는 JSON 문제은행으로 관리됩니다. 현재 문제은행 코드: - (협동전은 세 기기의 문제은행 코드가 같아야 같은 문제가 나옵니다)

🌐 실시간 랭킹 서버 연결 (구글 시트 + Apps Script)

서버 코드(thermo_ranking_apps_script.gs)를 구글 시트에 설치해 배포한 뒤, 나온 웹 앱 URL(…/exec)을 아래에 붙여 넣으세요. 연결되면 학생이 게임을 끝내는 순간 점수가 자동 등록되고, 개인전·협동전 랭킹이 따로 집계됩니다. 보드판은 매주 월요일 0시(한국 시간)에 새로 시작되고, 서버에는 이름(별명)·점수·시간 기록만 저장됩니다.

서버 주소는 게임 파일에 미리 들어 있어서 학생들은 게임 주소만 열면 자동 등록됩니다. 이 칸은 서버 주소를 바꿀 때만 쓰세요. 협동전은 팀마다 서로 다른 방 코드를 써야 팀별로 따로 집계돼요.

내려받은 JSON 을 편집기로 열어 문제를 추가·수정한 뒤 다시 불러오면 됩니다. 객관식은 opts[0]이 정답이며 게임에서 선택지가 자동으로 섞입니다. 불러온 문제은행은 이 기기의 브라우저에만 저장되고, 외부로 전송되지 않습니다.

① 턴 종료 & 3 AP 충전
